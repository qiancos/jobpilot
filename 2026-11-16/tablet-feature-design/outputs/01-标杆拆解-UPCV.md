## 2. 产品定位（E1 / E6）

> 「专业的求职顾问 AI，帮你搞定写简历、找职位、面试全流程，一路陪你拿 Offer」
> 四件套：AI 简历 / 求职 Agent / 浏览器插件 / ClawJob（MCP + Skills）

它把求职拆成一条**六幕任务流**，并在首页把这个流程直接产品化：

```
01 输入任务 → 02 分析背景 → 03 匹配职位 → 04 定制投递 → 05 模拟面试 → 06 拿到 Offer
```

这条「任务流叙事」是它最强的地方：用户不需要理解功能菜单，只要说一句「我想找上海的产品经理岗位，偏成长型团队」。

## 5. 它真正解决的三类问题（提炼）

1. **决策成本**：不是给更多岗位，而是给「92 分 + 两条理由 + 一条风险」——把「投不投」变成 3 秒判断。
2. **重复劳动**：JD 对齐、招呼语、网申字段、跟进状态，全部流水线化，并用 `0 / 47` 这种进度让人敢放着跑。
3. **不确定性**：六幕任务条 + 投递四栏 + 面试报告，把「我投出去的东西现在怎么样了」变成可见状态。

## 7. 对「投递驾驶舱」的直接启示

1. **抄任务流，不抄菜单**：把「采集 → 打分 → 勾选 → 话术 → 确认 → 执行 → 核验 → 跟进」做成一条可见进度的流水线。
2. **抄三件套与风险提示**：匹配结果必须是「优势 / 不足 / 建议」，且优势要引用 JD 原文——这一点与 PRD F3 完全一致。
3. **抄「确认才发送」的边界**：UPCV 明确不自动发送、不自动提交；我们的「每批人工确认」不是妥协，是同类产品的共识。
4. **不抄逐岗定制 PDF**：UPCV 的核心成本项，对我们（27 届、6–7K、实习/初级岗）投入产出比低；改为 3 个方向版本。
5. **它缺的三件事正是我们的主线**：移动端形态（平板 + 悬浮面板）、送达核验（L3）、话术质量闸门。
