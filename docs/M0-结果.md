## 三个重要结论

### 1. `webdriver = false` —— 这是最关键的一条

你在 PC 上踩过的 `code:37`（插件浏览器带自动化标记 → 职位接口全挂 → 循环跳安全页），
在 WebView 里**不复现**。原因是 WebView 没有 `navigator.webdriver` 这个标记。

这意味着 PRD §4.2 押的 A 路线成立。

### 2. 选择器修正了一处

我原来的 `.job-card-wrapper` **是错的**（0 命中）。真实结构是：

```
li.job-card-box              ← 卡片容器
└── div.job-info
    └── div.job-title.clearfix
        └── a.job-name       ← 岗位名
```

已写进 `jobpilot/probe/selectors.json`（唯一出口，改版只改它）。

### 3. 横屏才是正确姿态

| 姿态 | 分辨率 | 观感 |
|---|---|---|
| 竖屏 | 2064×3096 | 能用，但右栏偏窄、字号偏小 |
| **横屏** | **3096×2064** | **PC 版三栏完整，一屏 10 个岗位 + JD 全文** |

PRD 里"平板横屏双栏"的设计可以坐实。

## 顺手做出来的两个工具

1. **APK 支持 adb 指定起始页**，验证任何页面不用重新打包：
   ```powershell
   adb shell am force-stop com.jobpilot.pad
   adb shell am start -n com.jobpilot.pad/.MainActivity -e url "https://www.zhipin.com/job_detail/xxx.html"
   ```
2. **WebView 远程调试已开启**：PC 上 `chrome://inspect` 能直接审这个壳里的页面
   （`WebView.setWebContentsDebuggingEnabled(true)`）。

## 卡在哪：需要你登录

现在 App 里是未登录态（右侧还是手机号登录框）。未登录时：

- 看不到完整 JD
- 进不了聊天页 → 测不了发送键和会话选择器
- 看不到「今日沟通次数」配额

**下一步**：在平板上点右上角「登录/注册」，用手机扫码（或手机号验证码）登录。
登录完告诉我，我立刻跑聊天页那组自检，M0 就闭环了。

> 注意：登录会把你在 PC 上 Edge 的登录踢掉（PRD §13 R3）。
> 这正好是我们要的——**以后只在这台平板上保持登录**，符合"单设备"的风控原则。
