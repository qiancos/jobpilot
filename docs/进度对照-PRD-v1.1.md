## 3. 已发现的 6 个问题

### P0-1 无障碍被系统重置后，采集直接失效

vivo 每次更新 App 都会清掉无障碍授权。实测现在是 `null`，而 App **没有任何提示**——用户点采集只会看到"读到 0 张卡"。

### P0-2 两种采集源的去重键不统一

- 网页通道：用 BOSS 的 `job_id`
- App 通道：用 `公司|岗位` 哈希

**同一个岗位从两条路进来会存两条**。清单里已经能看到网页来的（无薪资）和 App 来的（有薪资）混在一起。

### P0-3 数据表缺 4 张

没有 `score / greeting / application / company`，意味着打分、话术、台账、漏斗、核验**全都无从落地**——不是没写界面，是没地方存。

### P1-4 清单没有排序和筛选

PRD F2.4 要求"按匹配分/薪资/活跃度排序、排除已投公司"，现在只有"只看已选"一个开关。

### P1-5 面板参数不持久化

档位、上限、间隔重启即丢。

### P2-6 版本号与实际不符

装的是带 Shizuku 的包，但 `versionName` 还是 0.3.0，看不出改了什么。

### ① 数据库 v2：补齐 5 张表

```
greeting    0 行   （话术 + 闸门结果 + 指纹）

```

索引：`idx_job_dedupe`（唯一）、`idx_app_job`、`idx_app_state`。

### ② 统一去重键

新增 `Keys.dedupe(company, title)`：
- 公司名去括号、去「有限公司/科技/网络/广州」等后缀 → `某某信息科技有限公司` → `某某信息`
- 岗位名去括号、去标点、转小写
- 键 = `公司归一化|岗位归一化`

迁移结果：37 条全部回填 dedupe_key，**37 条 = 37 个不同键，0 重复**，唯一索引建立成功。

冲突策略：INSERT 冲突时**补齐空字段**（网页抓的行没薪资，App 抓的行补进来），而不是简单丢弃。

### ③ 无障碍自检

- 首页顶部：未开启时显示**琥珀色卡片**「无障碍服务未开启 + 去开启」
- 采集页工具栏：左侧**状态芯片**，已开=绿色「无障碍 ✓」，未开=琥珀「无障碍未开」，点一下跳设置
- 实测：芯片正确显示 ✓（当前 `enabled_accessibility_services` 已包含我们的服务）

### ④ 首页（01 屏）

新 `HomeActivity`，现在成为启动页：

| 区块 | 内容 |
|---|---|
| KPI | 今日采集 37 / 待你审 37 / 已选 2 / 已投 0（全部来自真实数据库） |
| 无障碍卡 | 未开启时琥珀色 + 「去开启」 |
| 接着做 | 按状态给下一步（无岗位→去采集；已选→写话术） |
| 入口 | 开始采集 / 待投清单 / 打开 BOSS 网页版 / 权限设置 |

实测：首页渲染正常，KPI 与实际数据库一致；点「开始采集」能进入采集页。
