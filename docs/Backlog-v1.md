# JobPilot 任务清单 v1（待确认）

> 用法：这是**开发前的确认单**。你在「确认」列打勾或划掉，我按勾选的顺序开工。
> 估时是 AI 辅助开发下的人日（含调试），不含你的评审时间。

---

## 0. 一句话路线

**M1 先让东西能投出去 → M2 保证送到位 → M3 保证话说到位 → M4 把回复接住 → M5 扩到网申**

理由：你现在的痛点是"投了没回"。**投得出去**是前提，**送到位**是底线，**说得好**才是增量。顺序反了会做一堆漂亮功能却验证不了。
